Consider a singly linked list of unknown size. You can assume that the last node has `NULL` or `nullptr` set as its `next` value and there is a reference to the `HEAD` of the linked list which can be passed into your method / function.

1. Write the pseudocode for an algorithm that finds the value stored in the second to last node of this singly linked list.
1. Calculate the time complexity of your algorithm. Prove your answer.

Consider a singly linked list of unknown size. You can assume that the last node has `NULL` or `nullptr` set as its `next` value and there is a reference to the `HEAD` of the linked list which can be passed into your method / function.

1. Write the pseudocode for an algorithm that reverses this singly linked list.
1. What is the time complexity of your algorithm? Prove your answer.

---

Consider a doubly linked list that uses sentinel nodes to mark its beginning and end.

1. Write the pseudocode for an algorithm that takes two of these doubly linked lists and returns `true` if they store the same sequence of elements or `false` otherwise.
1. What is the time complexity of your algorithm? Prove your answer.
