## 🔖 Background Information

Fizz buzz is a word game for children to teach them about multiples of numbers. Players count upwards from one, replacing any number divisible by three with the word "fizz", any number divisible by five with the word "buzz", and any number divisible by both three and five with the word "fizzbuzz" [@FizzBuzz2026].

## 🎯 Problem Statement

Implement a program that takes a numeric input from the user and then prints the number, "fizz", "buzz", or "fizzbuzz" according to the rules of Fizz buzz.

## ✅ Acceptance Criteria

* You do not need to implement any validation for user input. You can always assume that the user enters a valid positive integer.
